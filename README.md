# «Бюджетограмма» — учебный full-stack проект для эксплуатационной практики

«Бюджетограмма» — небольшое веб-приложение для учета личных доходов и расходов и контроля месячных лимитов по категориям. Проект выполнен как практическая часть производственной (эксплуатационной) практики по направлению 02.03.03 «Математическое обеспечение и администрирование информационных систем», профиль «Разработка программного обеспечения (Full-stack разработка)».

## Возможности

- регистрация и вход пользователя через ASP.NET Core Identity;
- добавление, изменение и удаление доходов/расходов;
- категории, даты и описание операций;
- сводка за текущий месяц: доходы, расходы, баланс;
- месячные лимиты по категориям;
- предупреждение о превышении лимита;
- экспорт операций в CSV;
- изоляция данных разных пользователей;
- модульные тесты xUnit для финансовых расчетов.

## Стек

- .NET 8 / ASP.NET Core MVC;
- Razor Views;
- Entity Framework Core;
- SQLite;
- ASP.NET Core Identity;
- xUnit.

## Запуск

Требуется .NET SDK 8.

```bash
dotnet restore
dotnet run
```

База данных `byudzhetogramma.db` создается автоматически при первом запуске. Адрес приложения будет показан в терминале. Для первого использования откройте страницу регистрации через меню «Регистрация».

## Тесты

```bash
dotnet test Byudzhetogramma.Tests/Byudzhetogramma.Tests.csproj
```

## Структура

- `Models/` — модели финансовой операции и лимита бюджета;
- `Data/` — контекст Entity Framework Core;
- `Controllers/` — контроллеры сводки, операций и лимитов;
- `Services/` — финансовые расчеты и контроль превышения бюджета;
- `Views/` — Razor-представления пользовательского интерфейса;
- `wwwroot/` — стили;
- `Byudzhetogramma.Tests/` — модульные тесты.

## Ограничения учебной версии

Проект не подключается к банковским API, не выполняет реальные платежи и не хранит реквизиты банковских карт. Для промышленной эксплуатации потребуются серверная СУБД, HTTPS, управление секретами, резервное копирование, мониторинг и расширенное тестирование.

## Интерфейс
В проекте используется единая русскоязычная тема: формы создания и изменения данных центрируются в рабочей области, страницы входа и регистрации локализованы и оформлены в фирменной палитре «Бюджетограммы».
